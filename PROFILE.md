# AssetFare

A capped, non-custodial route API for AI agents across Solana, Base,
Arbitrum, and Robinhood Chain. Its public v2 surface provides fee-inclusive
quotes for 72 directed routes among nine asset endpoints from $1 through
$1,000. AssetFare never receives private keys and never signs or submits,
framing itself as one route candidate rather than a market-wide best-price
aggregator.

- **AssetFare Four-chain Agent API v2** — Public REST quotes and bounded
  unsigned actions that callers verify, sign, and submit across nine endpoints
  on Solana, Base, Arbitrum, and Robinhood Chain. The server never signs or
  submits. (`https://api.assetfare.dev`)
- **AssetFare Legacy Workflow API v1** — Original Solana-origin compatibility
  workflow with public quote/status/manifest endpoints and authenticated
  session resources. (`https://api.assetfare.dev`)
